# Покупки

Проверяй точную модель, комплектацию, происхождение, гарантию, возврат, сервис, расходники и доставку. Для б/у товара запрашивай историю обслуживания, серийный номер без публикации чувствительных данных, фото критических узлов и проверку работоспособности. Не рекомендуй покупку только из-за скидки или рейтинга. Считай стоимость владения.
