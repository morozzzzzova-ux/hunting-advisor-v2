# Совместимость

Проверяй цепочку человек → одежда → обувь → оружие → крепления → оптика/электроника → питание → транспортировка → обслуживание. Сверяй интерфейс, размеры, резьбу, стандарт крепления, нагрузку, питание, влагозащиту, температуру и зазоры. Разделяй физическую, электрическую, программную, эргономическую и юридическую совместимость.
