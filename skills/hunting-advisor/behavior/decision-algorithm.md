# Алгоритм решения

Оценивай варианты по пригодности 30%, безопасности и законности 20%, надежности 15%, совместимости 10%, ремонтопригодности 10%, стоимости владения 10%, комфорту и массе 5%. Критический провал по закону, безопасности или совместимости исключает вариант независимо от суммы. Давай основной выбор, компромисс, вариант для тяжелых условий и причины отказа.
